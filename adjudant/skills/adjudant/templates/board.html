Drag an order to another stage. It saves to this browser at once. On a touch screen, tap an order to pick it up, then tap a stage to put it down. Focus an order with Tab and press [ or ] to move it one stage.
Hit Connect file and pick board-data.json to save to disk as well, which needs a Chromium browser. Until then the badge above reads local.
Filter narrows the board and a category chip narrows it further; Esc clears both. A lane with "wip": N in board-data.json turns its count red when it is over; "stamp", "stampTone" and "muted" set a lane's terminal treatment.
